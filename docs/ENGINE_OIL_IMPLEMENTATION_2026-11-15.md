# 엔진오일 전환 구현·검증 (2026-11-15)

## 적용한 범위

일반 정비 항목 선택, 경고등 조회·구독·전송·판정·알림과 전용 진단·시연을 제거했다. 경고등 배너 리소스 120개(5,356,122 bytes)를 삭제했다. 주유·세차·엔진오일 교체와 기존 Bluetooth/날씨/세차 정책은 유지한다. 기존 일반 정비 기록은 읽기·ID·삭제 호환성만 남기며 ENGINE_OIL이 명시된 기록만 교체 기준으로 쓴다. 새로 들어온 미추적 배너 원본 이미지에는 손대지 않았다.

[합의 정책](engine-oil/ENGINE_OIL_POLICY.md)과 공급 JSON을 적용한다. JSON 하나를 두 앱의 빌드 자산으로 복사하므로 별도 주기 표를 수동 관리하지 않는다. 37개 차종/29개 대상 정책과 변형 모델 이름을 대조했다. 현재 차량 등록에는 연식·엔진·국가 선택이 없으므로 **차종별 최단 참고값**을 사용하고 이 한계를 표시한다. 모든 차량을 임의의 5,000km로 통일하지 않는다. BEV/FCEV는 제외한다.

- 마지막 교체일: 날짜, 약 1개월/3개월 전, 6개월 이상 전, 모르겠음. 교체 당시 실제 km는 선택 입력이다.
- 가입일·차량별 최초 유효 누적거리·선택 규칙/버전·초기 이력 출처를 저장한다. 가입 전 날짜만 아는 이력에는 20km/일을 한 번 적용하고, 가입 후에는 확인된 누적거리 증가분만 더한다. 누락 구간에 평균 거리를 중복 가산하지 않는다.
- 달력 개월과 실제 거리 중 먼저 도달하면 교체 시기다. 잔여율은 거리·기간 중 큰 사용률로 계산하고 0~100%로 제한한다. 종합 정보가 부족하면 퍼센트는 공란이다. 예상 교체일의 이후 주행량은 20km/일 가정임을 표시한다.
- 이력 없음은 100% 초기화가 아니다. 설치 이후 주기 도달을 따로 안내한다. 날짜 없이 실제 교체 km만 알면 거리만 안내한다. 새 확정 교체의 날짜만 있으면 기간만 안내하며 가입 전 평균을 덧붙이지 않는다.
- 직접 기록 추가/수정/삭제를 양쪽 앱에서 유지한다. 현재 날짜의 새 직접 기록에는 60초 이내 확인된 현재 km가 있을 때만 연결한다. 재연결된 며칠 뒤 km를 과거 교체 거리로 넣지 않는다. 날짜 변경은 이전 km 기준을 무효화한다. 재전송과 삭제 tombstone을 보존한다.
- 차량 원장의 거리와 가입 기준을 휴대폰에 전송한다. 서로 다른 가입일·지연/역순 프레임에서도 이전 거리로 되돌아가지 않도록 병합한다. 다른 등록의 원장은 섞지 않는다.
- 화면·캐릭터·배너·런처의 세 번째 조건은 경고등이 아니라 같은 엔진오일 계산 결과다. 교체 주기/알림 단계 키를 저장해 단순 재시작·재전송으로 재발송하지 않는다. 새 배너 그림은 아직 적용하지 않았다.

## 사진의 네 항목: 실제 확인 범위

| 항목 | 결과 |
|---|---|
| 실제 시동/전원 OFF→ON 수신 | **현재 자동 경로 비활성.** 사용 중인 Vehicle SDK 2.3.2의 Vehicle 진입점과 공개 도메인 API를 javap으로 확인했으나 실제 차량 전원/ignition/DrivingReady 조회·구독 API를 찾지 못했다. HVAC power 및 PowerDownWarningIndicator는 차량 전원 OFF가 아니다. SDK 연결 끊김·BT 단절·속도 0·P/N·엔진 자동 정지를 OFF로 바꾸지 않는다. 실차 전원 사이클 통과를 주장하지 않는다. |
| 같은 정비소 판정 | **실제 검증 안 됨/자동 경로 생략.** 전원 증거를 확보하지 못했으므로 세차의 3분/20m 예외나 예전 20분 체류를 엔진오일 질문에 전용하지 않았다. 실제 시설 ID·구역·위치 정확도/최신성·출차/다음 정차 검증이 갖춰져야 활성화할 수 있다. |
| 대기 중 앱 종료 | **OFF 대기 방문 복원은 미구현/비활성.** 만들어지지 않은 방문을 복원했다고 보고하지 않는다. 별개로 가입 기준일·실제 거리·초기 이력 원장을 저장하고 객체를 다시 만든 뒤 동일 계산이 복원됨을 두 AVD에서 검사했다. 실제 프로세스 강제 종료/재부팅의 OFF 방문 복원 시험은 아니다. |
| 반복 질문/중복 기록 | 자동 방문 질문을 생성하지 않으므로 그 응답/오프라인 질문 동기화는 현재 범위에 없다. **직접 교체 기록의 같은 ID 재전송 → 기록 하나/완료 이력 하나**, 삭제 후 오래된 기록 재전송 → 삭제 유지, 주기별 배너 중복 방지를 검사했다. |

최신 방문 목표는 같은 정비소의 **실제 전원 OFF→ON 30분 이상, 출차, 다음 차량 정차**다. 이전 20분 연속 체류 구현 초안은 삭제했다. 정책 §10이 허용한 대로 현재 지원되지 않는 자동 경로를 생략하고 직접 기록으로 보완한다. 자동 경로/확인 배너/방문 증거 영속화가 완성됐다는 뜻이 아니다.

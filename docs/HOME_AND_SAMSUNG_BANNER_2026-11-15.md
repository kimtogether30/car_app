# 홈 구조 및 삼성 패드 알림 확인 (2026-11-15)

두 앱의 홈 순서를 공통 CareHomeLayout으로 묶었다: 헤더 → 캐릭터/차량 정보 → 연료·배터리/청결도 → 최근 관리일 → 날씨 → 주변 찾기. 화면에 맞는 글자·터치 크기는 유지한다. 엔진오일 퍼센트/확대 카드는 제거하고 교체 시기 계산과 캐릭터·런처·배너는 유지한다.

실물 Tab S7 SM-T875N / Android 13에 휴대폰 앱을 설치했다. 실제 기록을 건드리지 않는 phone.verification 앱에서 같은 production 알림 빌더를 이용해 설정 앱 위에 6상태 알림을 10초 간격으로 표시했다. 앱 지정 Notification.color 및 largeIcon 검사는 통과했지만 실제 삼성 간략 팝업은 왼쪽 자동차/원형 배경을 파란색으로 유지하고 캐릭터 그림을 생략했다. 이 결과는 색값 검사 통과만으로 화면 색상까지 통과라고 할 수 없음을 확인한다.

같은 엔진오일 알림을 삼성 ‘자세히 보기’로 비교하니 왼쪽 원형 배경이 보라색이고 오른쪽에 보라 캐릭터가 표시됐다. 앱 코드의 색 지정과 삼성 간략 팝업 표현을 구분한다. 시험 뒤 edge_lighting=1(원래 간략 보기)로 복원하고 검증 앱을 비활성화했다. 자세히 보기를 제품 앱이 강제로 변경하지 않는다.

화면 증거(Git 제외): build/verification/tab-headsup-fuel.png, tab-headsup-oil-detailed.png. 개인정보가 있는 전체 설정 화면을 저장소에 포함하지 않는다.

자동 기록의 현재 범위: 세차는 조건을 충족한 EstimatedVisit을 먼저 기록하고 부정 응답 시 취소한다. 주유는 확정 감지 이벤트와 완료 알림이 있으나 관리 기록 자동 추가 연결은 없다. 엔진오일 자동 정비소 질문은 실제 전원 API 미확인으로 비활성이며 직접 교체 기록을 등록한다. 세 항목 모두 자동 기록이라고 설명하지 않는다.

검증 마무리: 양쪽 debug/verification 빌드와 기존 단위 테스트(차량 39/휴대폰 102 중 선택 외부시험 2개 제외)는 통과했다. 공통 레이아웃 적용 후 Pleos 실제 렌더링 시험 homeUsesOilCharacterWithoutPercentageCard 통과 및 화면 캡처를 확인했다. 차량·패드 실제 앱은 데이터 보존 업데이트했고 검증 복사본은 비활성화했다. 패드는 신규 설치여서 차량 미등록 상태이며 사용자 차량을 임의 등록하지 않았다.

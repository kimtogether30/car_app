# 엔진오일 관리 정책 안내

일반 정비 선택과 차량 경고등 조회·알림 기능은 제거했습니다. 제품 항목은 주유, 세차, 엔진오일 교체입니다.

현재 제품 기준은 [엔진오일 합의 정책](engine-oil/ENGINE_OIL_POLICY.md), 차종별 주기는 [데이터 설명](engine-oil/README.md)을 따릅니다. 최신 방문 기준은 20분 관측 체류가 아니라 **같은 정비소의 실제 차량 전원 OFF→ON 30분 이상 + 출차 + 다음 정차**입니다.

이전 정비 기록의 종류·ID·삭제 정보는 저장 호환성만 유지합니다. ENGINE_OIL이 명시되지 않은 기록을 엔진오일 교체 이력으로 재해석하지 않습니다. 경고 해제·오일량 정상화는 교체 확인이 아닙니다.

현재 구현과 시험의 실제 범위는 [2026-11-15 결과](ENGINE_OIL_IMPLEMENTATION_2026-11-15.md)를 참고하세요. 문서의 제품 목표와 SDK 지원·실차 검증을 구분합니다.

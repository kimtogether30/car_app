# 새 배너와 엔진오일 추정 기록 — 2026-11-15

> 후속 사용자 변경: [동일 정비소 수신 공백 추정](ENGINE_OIL_RECEIVING_GAP_2026-11-15.md)을 추가했다. 아래 실제 전원 미지원 진단은 유지되지만, 현재 자동 감지는 실제 전원 경로 외에 별도 수신 공백 추정 경로도 사용한다.

사용자 최종 결정은 유효한 정비소 방문을 먼저 자동 추정 기록하고 “교체 안 했어요”로 취소하는 방식이다. 무응답은 기록을 유지한다. 수동 확정 기록과 `ENGINE_OIL / EstimatedOilVisit` 출처를 구분한다.

## 반영

- 휴대폰 새 이미지: 오일 주기 도달, 주유+세차, 주유+오일, 전체 주기 도달, 오일 추정 질문의 밝음/어두움 10개 리소스를 연결했다. 이전 6종과 합쳐 이미지가 있는 배너는 11종이다. 공급되지 않은 세차+오일 전용 이미지는 기존 텍스트 경로를 유지한다.
- 상단 작은 아이콘은 이전 커밋부터 상태별 캐릭터를 사용한다. 삼성 간략 팝업에서 보라 캐릭터 표시를 실제 캡처로 재확인했다. 시스템 팝업의 배경/글꼴/잘림은 OS가 결정한다.
- 고정바 안내 단계·설정 버튼·안내 파일을 제거했다. 수동 전체 가입은 6단계, 완전 자동 식별 차량은 3단계다.
- 휴대폰 미등록 차량 화면: 본문 30sp, 버튼 23/22sp, 최소 높이64dp, 최대 폭420dp, 사용 가능 화면 중앙 정렬. 실제 S7 화면을 확인했다.
- `기록 보기`는 해당 차량 관리기록으로 이동하며 초기 로딩 뒤에도 차량 선택을 유지한다. 취소는 기존 거절/삭제 식별자를 통해 역순 편집·재전송에서 보호한다.

## 자동 기록 조건과 실제 지원

같은 차량·지도상 구분 가능한 정비소 구역에서 실제 전원 OFF/LOCK→ON 30분 이상, 출차(D·실제 이동), 다음 실제 정차가 모두 필요하다. 마지막 날짜를 알면 가혹 주기 도달도 필요하며, 날짜 미상만 첫 기록 확보 예외다. 차량 위치에 실제 정확도가 없거나 폰 위치이면 기록하지 않는다. RPM0·P/N·속도0·Bluetooth 단절을 전원 OFF로 치환하지 않는다.

공개 AAOS IGNITION_STATE를 기존 Car 연결에 읽기 전용으로 추가했다. 정상 CAR_POWERTRAIN 권한 및 속성 지원을 확인한다. Pleos AVD에서 실제 조회 결과는 **Unsupported: VHAL IGNITION_STATE 미지원**이었다. 따라서 이번 환경에서는 실제 정비소 자동 기록을 완료했다고 주장할 수 없다. 수동 기록은 계속 가능하다. Vehicle SDK 2.3.2 자체의 전원 API가 지원된다는 의미도 아니다.

위치 정확도30m, 최대 사이클24시간은 보수적 구현 시험값이다. 실제 정비소 판정 범위로 검증된 수치가 아니다. 저장은 차량 ID별로 분리하고 OFF 시작·ON·출차·정차를 복원한다. 방문 ID로 중복 생성과 취소 복원을 차단한다. 원본 전원 이벤트 시각을 사용한다.

## 검사

- 앱/휴대폰 단위 검사 합계146개 실패0, 두 앱 빌드·린트 통과. 라이브러리 자체의 오래된 린트 검사 등 기존 경고는 남아 있다.
- EngineOilLedgerTest 10개: S7 및 Pleos 격리 앱 통과. 실제 차 신호/정비소 체류 시험이 아닌 저장소 fixture 검사다.
- 오일 방문 정책 단위 검사: 30분 경계, 다른 구역/경계, 위치 정확도 누락, 폰 위치, 출차·정차·신선도 누락 거부.
- S7 새 이미지22개 게시 및 중복 방지 통과. 실제 알림 부정 액션 취소·재전송 거부 통과. 다른 앱 위6상태 게시 및 얼굴 리소스/런처 별칭 변경 통과.
- Pleos 가입 검사5개 통과(자동 식별3개·전체 단계1개·기록 보존1개). 기록 보존 검사는 시스템 Pleos 위치 권한창으로 처음 실패했으며, 시험 앱의 정상 권한을 허용한 뒤 통과했다.
- 실제 위치/전원/정비소·30분 작업 및 S24↔S7 무선 왕복은 이번에 검증하지 않았다.
- 최종 실제 앱은 S7/차량 AVD에 데이터 보존 설치했다. 두 환경의 verification 앱은 데이터 보존 비활성화했고 S7 간략 팝업 설정(edge_lighting=1)을 유지했다.

스크린샷과 원시 검사 결과는 Git 제외 `build/verification/`에만 보관한다. 실제 사용자 기록은 시험으로 변경하지 않는다.

공개 API 근거: [VehiclePropertyIds.IGNITION_STATE](https://developer.android.com/reference/android/car/VehiclePropertyIds#IGNITION_STATE), [VehicleIgnitionState](https://developer.android.com/reference/android/car/VehicleIgnitionState). 실제 전원 속성이 제공되는 환경에서만 해당 의미를 적용하며 문서에 속성이 있다는 사실을 Pleos 지원 증거로 보지 않는다.

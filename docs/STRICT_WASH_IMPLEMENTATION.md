# 세차 구역·차량 상태 기반 추정 (2026-11-12 후속 요청)

이 문서는 같은 날의 이전 시설 반경 전용 정책을 대체한다. 자동 감지는 실제 물세척의 증명이 아니라 취소 가능한 EstimatedVisit이다.

## 운영 조건

| 경로 | 조건 |
|---|---|
| 공통 | 지도에서 구분 가능한 세차 구역에 실제 차량 위치로 진입. 시설 중심점/주유소 전체 반경은 자격 근거가 아님 |
| 컨베이어식 | 세차 구역 안의 유효 관측 체류가 180초 이상. 이동 시간도 포함. N 상태의 실제 차속 이동 근거, 이후 최신 D 전환, 실제 차량 출차까지 필요 |
| 정차식 | 세차 구역 안에서 최신 차속이 정확히0인 연속 관측 구간이 180초 이상. 이후 실제 차량 출차 필요. P/N만으로는 자격 없음 |
| 같은 자리 재수신 | 세차 구역 안의 정차(0m/s·최신 기어) 위치 저장 → 수신 공백 → 같은 구역20m 이내에서 최신 정차(0m/s·최신 기어) 신호 재수신. 전후 시각 차이를 체류 추정으로 더해180초 이상이면 자동/셀프 모두 확인 후보. 차량 출차 전에는 미반영 |
| 출차 | 경계 밖 차량 위치와 유효 비영 차속이 30초 이상 이어짐. 정차식의 실제 후진 출차도 허용. 폰 위치/수신 단절은 출차가 아님 |
| 배너 | 조건 충족 때 먼저 세차 추정 기록/청결도에 반영하고 ‘세차한 것 같아! / 세차한 게 맞아?’와 맞아요·세차 안 했어요 제공 |
| 응답 | 무응답은 적용한 기록 유지. 맞아요는 질문을 닫고 유지. 안 했어요는 취소하고 이전 유효 기록부터 재계산. 별도 응답 대기 타이머 없음 |

정차식은 180초를 채우기 전에 움직이면 정차 체류를 다시 센다. 이미180초를 채웠으면 구역을 가로질러 출차하는 이동 때문에 자격을 잃지 않는다. 긴 수신 공백/신호 오류는 원칙적으로 자격을 초기화하되, 아래 같은 자리 재수신 예외는 경과 시간을 추정으로 반영한다. 경계 완충 구간은 체류·출차 시간을 더하지 않되, 최신 차량 신호가 계속되는 정상 출차 과정에서는 이미 완료한 구역 내 패턴을 보존한다. 미완료 체류를 경계 흔들림으로 이어 붙이지 않는다.
연속 수신 경로에서 컨베이어 여부가 지도에 명시되지 않은 시설은 관측된 정차식 또는 컨베이어식의 **완전한 조건 중 하나**를 충족해야 한다. 같은 자리 재수신 예외는 아래 별도 추정 조건을 따른다. 자동세차라는 이름만으로 컨베이어라고 추정하지 않는다.

## 신호와 시험 기준

- 기존 공유 Pleos 위치·차량 SDK 연결 사용. 위치 콜백 때 실제 repository의 차속/기어 표본과 원래 측정 시각을 함께 캡처해 IO 작업으로 전달. 데모/오류/미수신은0으로 대체하지 않음.
- 차속은 측정→위치 수신 시각0~5초이고 위치 표본과 시각 차이가5초 이내여야 함. 기어는 측정→수신35초 이내. 새 시각의 같은 값은 유효하지만 캐시 시각을 갱신하지 않음.
- 위치는 측정→수신0~15초. 유효 관측 사이가15초를 넘으면 원칙적으로 체류 및 패턴 초기화. 단, 저장된 같은 자리 정차 전후 표본이 아래 예외를 충족하면 경과 시간을 추정으로 연결. 중복 측정 시각은 체류0초. 연속 수신 경로의180초는 콜백 개수나 빈 시간을 곱한 값이 아님. 같은 자리 재수신 예외에서만 전후 시각 차이를 추정 체류로 더함.
- N 이동은 인접한 유효 N·비영 차속 표본으로 최소5초, 보수적으로 적분한 이동량1m 이상을 관측해야 함. 한 번의 튐과 ±0.001m/s 수준의 작은 흔들림은 이 조건을 채우지 못함. 기준은 초기 시험값이며 SDK 보장값이 아님.
- 지도 경계10m 이내는 불확실로 보류. 미터 정확도가 실제 제공되면 그 값과10m 중 큰 완충값 사용. Pleos가 미터 정확도를 제공하지 않는 경우10m는 위치 정확도 보장이 아니라 시험 완충값일 뿐임.
- 휴대폰 위치는 차량에서 시작한 방문에 저장할 수 있으나 차량 차속·기어·정차 시간을 대신하지 않고 단독 출차/완료도 만들지 못함. 차량 수신 공백을 폰 위치만으로3분 정차로 채우지 않음.


## 시동을 끈 뒤 같은 자리에서 재수신 (최신 사용자 요청)

시동 종료 센서나 상시 실행을 보장하지 않는다. 다음은 **수신 공백 전후로 추정하는 경과 체류**다. 꺼지기 전 실제 차량 표본을 디스크에 저장하므로 앱 프로세스가 종료돼도 다음 실행에서 계산할 수 있다. 휴대폰 위치 보완을 켜 두지 않아도 이 경로는 동작한다.

0m/s이면 D/R도 정차로 인정한다. 시동을 다시 건 직후 D에 놓았다는 이유만으로 이 예외에서 배제하지 않는다.

1. 저장된 마지막 차량 표본이 지도 세차 구역 안, 유효0m/s, 최신 유효 기어(P/N/D/R)이어야 한다.
2. 15초를 넘는 공백 후 같은 등록 차량에서 새 차량 위치·차속·기어를 받아야 한다. 재수신도 세차 구역 안,0m/s,최신 유효 기어(P/N/D/R)이고 이전 위치와20m 이내여야 한다.20m는 위치 오차를 고려한 시험값이다.
3. 측정 시각 차이와 실제 수신 시각 차이가15초 이내로 일치해야 한다. 같은 측정 시각의 캐시 값은 재시동 근거가 아니며 오래된 차속/기어도 사용하지 않는다.
4. 공백 경과 시간을 그 이전에 관측한 정차 체류에 더한다. 재연결 직후Loading/NoData가 먼저 들어와도 마지막 실제 정차 표본을 보존해, 유효 신호가 준비되면 계산한다. 구역 밖 위치·실제 움직임·불확실한 경계가 관측되면 같은 자리 연결 근거를 버린다.
5. 합산180초 이상 후 실제 차량 출차30초가 관측되면 EstimatedVisit만 적용한다. 이 예외는 자동세차/셀프세차 모두 대상이며 N 이동 패턴을 실제 관측했다고 주장하지 않는다. 출차 전에는 배너/세차 반영을 하지 않는다.
6. 원시 방문 근거의 기존 유효기간은 방문 시작부터2시간이다. 이를 넘긴 뒤 재시동한 경우 자동 추정하지 않는다. 위치가 다르거나 구역 밖에서만 재수신된 경우, 폰만 복귀한 경우, 전후 차량 신호가 부족한 경우도 공백을 채우지 않는다.

세차장 안에 주차하고 다른 일을 본 경우와 실제 세척은 센서만으로 구별할 수 없다. 같은 자리 정차·경과 체류·차량 출차가 충족돼도 **확인 배너**로 안내한다. 무응답/맞아요는 적용한 추정을 유지하고, 세차 안 했어요는 취소·점수 복원한다. 세차장 근처라는 이유만으로 구역 밖 주차를 이 예외에 넣지 않는다.

## 지도 연결과 한계

기존 승인 Overpass endpoint 및 동일한10km/최대20개 조회 범위를 사용한다. 세차 조회만 `out body geom;`으로 경계를 받는다. `amenity=car_wash`인 닫힌 way(최대256점)만 자동 감지 영역으로 사용한다. 주유소 way, 점 POI, 열린 way, 현재 지원하지 않는 relation은 자동 감지하지 않는다. 일반 주변 검색에서는 계속 표시할 수 있다. 임의의 원/사각형으로 세차 구역을 만들어내지 않는다.

OSM 세차 영역이 없거나 너무 좁거나 잘못 그려졌으면 자동 감지가 누락될 수 있다. 지도 영역 자체에 대기 장소가 포함되거나 위치가 틀리는 경우 실제 세척 여부를 완전히 판별할 수 없으므로 확인·취소 배너를 유지한다. 전국 모든 시설의 자동 감지나 주유·대기 오탐0건을 보장하지 않는다. 주유 구역 등 세차 영역 바깥에서 기다린 시간은 세차 체류로 합산하지 않는다.

## 저장·재전송·업그레이드

기존 수신 차량의 stable vehicleId로 저장. 화면에서 보는 차량은 SDK 수신 차량을 바꾸지 않는다. IO 전용 방문 저장소, 기존 BT 프레임을 사용하며 새 서버/의존성/폴링을 추가하지 않는다.

방문 프레임 policy=2에 경계와 표본별 원래 차속/기어 시각 포함. 최대4방문×720표본, 원시 근거 유효기간2시간. 최대 표본에 도달한 미완료 방문은 다음 관측 때 새 방문으로 다시 시작하며 이전 체류를 넘겨주지 않는다. 차속/기어 추가로 프레임이 과도하게 커지지 않게 제한했다.

기존 radius 접두 ID는 호환을 위해 유지하지만 policy=2와 실제 경계/신호가 없는 예전 원시 방문은 새 추정을 만들지 못한다. 업그레이드 때 기존 확정/추정 사용자 기록이나 거부/삭제 tombstone을 지우지 않는다. 취소한 방문의 재수신, 무응답/맞아요 뒤 재전송, 앱 재시작에도 중복 반영하지 않는다.

질문은 기존처럼 적용 시점부터7일간 표시/취소 가능하며, 응답하지 않아 표시 기간이 지나도 세차 기록은 유지된다. 알림 권한이 없으면 OS 알림 전달을 보장하지 않지만 저장된 앱 내 확인 배너 경로는 유지한다.

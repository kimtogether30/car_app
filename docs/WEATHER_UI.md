# 현위치 주간 날씨·자동 갱신·세차 날짜 추천

2026-11-12. 정원이의 원격 커밋 `67bad8c`, `adf9972`의 주간 예보와 주행 날씨를 유지하고 공통 `ForecastWeatherPanel`을 차량·휴대폰 홈에 연결했다. 사용자 요청에 따라 수동 지역 선택을 현위치 방식으로 변경했다.

## 현위치와 예보

- 휴대폰은 Android 위치 권한으로 기기 위치를 받는다. 2026-11-12부터 **대략적인 위치(ACCESS_COARSE_LOCATION)만** 선언·요청한다. 정확한 위치를 함께 요청하면 Android 12+ 권한 창이 ‘정확/대략’ 선택을 띄우므로 제외했다. 0.05도 예보 구역에는 대략 위치로 충분하며, Android 12+에서는 대략 권한으로도 GPS 제공자를 읽고 시스템이 좌표를 흐려서 준다. 권한 창 문구는 앱이 아니라 휴대폰 언어 설정을 따른다(한국어 기기에서 한글). 백그라운드 위치 권한은 요청하지 않는다. 최초 홈에서 권한을 요청하며 거절하면 ‘위치 허용’, ‘기준 → 위치 설정 열기’로 다시 설정할 수 있다.
- 차량은 `pleos.car.permission.FUSED_LOCATION`과 기존 공유 Pleos 위치 수신을 사용한다. Google 위치 SDK나 휴대폰 위치를 차량 SDK의 위치인 것처럼 대체하지 않는다. 날씨용 임시 SDK lease는 요청 완료/취소 시 해제하고 기존 수신 소유자는 유지한다.
- 화면 진입/복귀, 자동 갱신, 수동 새로고침마다 60초 이내 위치를 확인한다. 요청은 최대 20초이며 화면 숨김/홈 이탈 때 취소한다. 별도 추적 서비스나 새 반복 위치 폴링은 없다.
- 0.05도 구역 대표 좌표를 Open-Meteo에 보내 예보를 조회한다. 이는 지역 예보를 공유하기 위한 구역이며 관측 정확도/해상도를 뜻하지 않는다. 위치·원시 응답을 로그로 남기지 않는다.
- 현위치를 못 받으면 날짜 추천을 보류하고 미수신 표시를 사용한다. 이전 도시나 이전 현위치 캐시를 현재 위치로 표시하지 않는다. 과거 수동 선택 도시는 새 현위치로 간주하지 않는다.
- 한국 시간 `Asia/Seoul` 기준 오늘~+6일의 7일 예보. 날씨 아이콘은 WMO 코드, 표시 기온은 일 최고 기온이다. 일별 코드는 그날 가장 심한 날씨이며 하루 종일 같은 상태라는 의미가 아니다.
- 최저/최고 기온, 최대 강수확률(%), 총강수량(mm), 강설량(cm)의 null/0/음수를 구분한다. 총강수량에 눈의 물 환산량이 포함되므로 눈 cm를 다시 더하지 않는다.
- 캐시는 안정적인 vehicleId로 분리하며 실제 수신 차량을 변경하지 않는다. 두 기기는 각 기기의 현재 위치를 사용하므로 서로 멀리 있으면 예보가 다를 수 있다. 현재 위치 표시용 휴대폰 좌표를 주행 구간/세차 감지/BT 스트림에 추가하지 않는다.
- 좌표를 포함한 날씨 캐시·주행 장부는 차량 앱 백업/기기 전송 제외, 휴대폰은 기존 전체 백업 제외를 유지한다. 기존 정비 기록·다중 차량 ID·삭제 상태는 보존한다.

## 갱신

- 위치 확인 후 같은 구역의 캐시가 없거나 1시간 경과·한국 날짜 변경 시 조회한다. 다른 구역으로 이동했으면 새 예보를 조회한다.
- 화면이 보이는 동안 다음 만료/한국 자정에 갱신한다. 숨기거나 홈을 떠나면 타이머·화면 요청을 취소한다. 새 WorkManager/서비스를 추가하지 않았다.
- 수동 새로고침은 위치와 예보를 모두 다시 확인한다. 요청 중 중복 호출과 15초 이내 반복 클릭을 제한한다.
- 날씨 HTTP 실패 시 현재 구역의 캐시가 있으면 유지하고 ‘갱신 필요’를 표시한다. 위치 실패 시에는 이전 구역 날씨를 표시하지 않는다. 화면이 보이면 10분 후 재시도한다.
- 서버 변경 푸시가 아니다. 변경은 다음 API 조회에 반영된다. 마지막 수신 시각은 모델 생성/현장 관측 시각이 아니다.

## 세차 날짜 추천: 앱 참고용 규칙

당일과 다음 날 모두 다음 조건에 맞는 가장 빠른 날을 추천한다.

| 항목 | 조건 |
| --- | --- |
| 날씨 코드 | 맑음·구름·안개 범위. 비/눈/뇌우와 알 수 없는 코드 제외 |
| 최대 강수확률 | 30% 이하 |
| 총강수량 | 0.5mm 미만 |
| 강설량 | 0cm |
| 기온 | 최저 0℃ 초과, 최고 35℃ 미만 |
| 데이터 | 필요한 필드 누락 없음, 수신 6시간 이내, 한국 오늘 기준 예보, 현위치 확인됨 |

7일째는 다음 날 자료가 없어 단독 후보로 사용하지 않는다. 적합한 날이 없으면 임의 날짜를 만들지 않는다. 공식 기상기관의 세차 기준이나 날씨 보장이 아니다.

추천은 점수·세차 기록·알림을 변경하지 않는다. 친구가 구현한 과거 실제 주행 구간의 거리/시간별 모델 날씨/72시간 보완은 기존 정책대로 유지한다. 미래 일별 예보로 현재 청결도를 미리 낮추지 않는다. `DRIVING_WEATHER_IMPLEMENTATION.md`, `WASH_POLICY.md` 참고.

## 화면과 키보드

캐릭터는 원래 가운데 위치·고정 크기(휴대폰 190dp, 기본 Pleos 390dp)를 유지하고 말풍선은 확대 전 설정이다. 캐릭터 아래 행은 왼쪽 차종–가운데 닉네임–오른쪽 번호판이며 닉네임과 번호판은 같은 글자 크기(휴대폰 14sp, 차량 24sp)다. 큰 글씨/좁은 화면에서는 내용을 보호하는 스크롤을 유지한다.

한국어 입력 힌트와 조합 입력은 유지한다. 한글이 조합되면서 키 캡션이 영문으로 보이는 것은 개발 에뮬레이터의 Fcitx 입력기 상태였으며, 2026-11-12부터 `toolsphone-hangul-keyboard.cmd`로 ReteKey 한글 자판을 쓴다([OTHER_PC_TESTING.md](OTHER_PC_TESTING.md)). ReteKey 실험은 화면 키보드 숨김 문제로 원복했고 KeliBoard 설치는 선언 권한에 대한 자동 승인 검토 거절로 실행하지 않았다. 한글 자판 자체가 불가능하다는 의미는 아니며, 사용자 기기 입력기를 앱이 강제로 교체하지 않는다.

## 검증

- 현위치 구역/위치 유효 시각 경계 포함 JVM 88개 통과, 실패/오류 0. 양쪽 앱 및 검증 APK 빌드 성공.
- 휴대폰 Android 4개 통과: 실제 Open-Meteo 예보와 수동 새로고침, 캐시 차량/구역 분리, 현위치 미수신 시 과거 고정 도시 숨김, 위치 어댑터의 신선한 에뮬레이터 좌표 수신.
- 네트워크 및 에뮬레이터 위치 검사는 공개 서울 좌표와 분리된 verification 앱을 사용했다. 실제 GPS·Pleos 위치·물리 Bluetooth 성공으로 해석하지 않는다. 실기기 확인은 BT-51.
- 캡처와 실행 로그: `build/diagnostics/weather-home-20261112/current-location-*`.
